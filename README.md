# ⚡ FlashQuiz

FlashQuiz är ett Quiz som handlar om TV-serien **The Flash**.
Du kan testa dina kunskaper genom att svara på frågor och välja olika svårighetsgrader.

## Funktioner

- 30 frågor om The Flash.
- Tre svårighetsgrader: Easy, Intermediate och Advanced.
- Flervalsfrågor med olika svarsalternativ.
- Poäng räknas automatiskt.
- Du kan spara ditt namn och ditt resultat.
- En topplista visar spelarnas poäng.
- Sidan fungerar på både dator och mobil.

## Tekniker
- C#
- .NET 10
- Blazor
- Razor Components
- HTML och CSS
- LINQ
- Dependency Injection (DI)

## Så startar du projektet

1. Ladda ner eller klona projektet från GitHub.

2. Öppna mappen `FlashQuiz`.

3. Öppna terminalen i projektmappen (cd FlashQuiz)

4. Skriv:

   ```bash
   dotnet run
   ```

5. Öppna länken som visas i terminalen.

## Resultat

Resultaten sparas tillfälligt medan appen körs. De försvinner när appen startas om.
